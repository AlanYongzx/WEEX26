### 你们的任务
你们的任务是**评估某一污染物排放源所排放的大气污染物对人体健康的影响**。

#### 你们的排放源位于哪里？
在 Moodle 上的 Excel 文件 `map.xlsx` 中，P 列“Emission site ID”用你们的团队名（如 A1、B2……）标注了你们的排放源。在每个国家中，不同团队可能同时研究同一个排放源。一个排放源可以是地理上的点源（如工厂），也可以是由大片区域构成的整个面源（如农业区）。

### 在周三 8:30 之前完成任务的步骤
为了完成第一项任务，你们团队须在周三 8:30 之前经历以下各步骤。这些步骤之间如何安排，由你们自行决定。
- 理解并把握：为评估排放源所排污染物对人体健康的影响，需要考虑哪些现象（系统性方框图）。
- 在已识别的现象中，评估哪些现象在影响上占主导地位。
- 形成一套数值模拟策略，以尽可能好地量化与排放源污染物相关的人体健康影响。
- 编写数值模拟代码，并在编写过程中逐步验证代码的行为。

为此，我们期望你们团队（周一、周二）做到以下几点：
1. 研读可用的文档和资源，使你们能够协商并选定由哪些同学负责深入研究每一项资源 / 在后续寻找额外资源，以服务于整个团队。
2. 协商并明确：
   a. 你们的工作策略：谁负责哪项任务，以实现团队目标；
   b. 为完成任务你们应处理的主要问题；
   c. 你们对所涉现象的认识（为表征并量化该情境，需要考虑的主要现象有哪些；用怎样的方框图来表示所涉各现象之间的联系）。

从周三上午起，每个团队将负责一项规模更大的任务，涉及大量排放源和更多样的现象。届时你们需要深化对相关现象的理解，并改进建模与计算方法，以便尽可能好地回应新任务。

Effergie 的最佳团队和 WFE 的最佳团队将分别由 Effergie 负责人和 WFE 团队选出。WFE 与 Effergie 的获胜团队将于**周五下午**，在为某议会调查委员会工作的专家面前进行科学辩论。每个团队需要展示其工作的科学质量，并说明自己的方法论为何优于对手团队。相关更多信息将于周三告知。

#### 周三 9:00–12:15：工作口头汇报。L1_3
周三 9:00 起，你们将在黑板前回答评审团的问题，**不得携带任何资料或电子设备**。约 17 分钟内，评审团将与你们交流，考察你们如何掌握关键现象，以及如何把数值模拟与相关现象衔接起来以最好地完成任务。

每个问题将随机抽取团队中的一人回答。我们期望团队中**每个人**都能回答所提出的问题——因此问题将与此要求相适应。例如，我们不会就 Matlab 代码提出尖锐细节问题，但我们期望全队都了解构建代码时的主要选择（边界条件等）。

你们将被要求解释：对于你们这个可疑排放源在环境中的污染物，你们是如何建模其人体健康影响的。排放源排出的污染物会经过不同的环境介质（compartiments）才对人体健康造成损害，并依照各种物理化学规律从一个介质转移到另一个介质：

a. 你们如何表示污染物在其中循环并最终分配的各个介质（大气、近地面的各类空气、各类水体……）？哪些现象支配着污染物从一个介质向另一个介质的转移？请使用方框图（https://en.wikipedia.org/wiki/Block_diagram）（https://scx2.b-cdn.net/gfx/news/2015/2-explanationo.jpg）。你们可以借鉴这两个参考中的示例，尽管它们与你们的具体情境并不直接相关。注意：不是要讲解该主题的宏大概论，而是要清楚、直接地说明你们**如何以及为何**选择这样开展计算，以得到尽可能好的定量结果。只选取你们能够进行定量分析的要素、现象和关系。这不是上一堂通识课，而是汇报你们的工程方法。

b. 你们如何构建数值模拟方法，以量化你们认为占主导地位的现象？

c. 论证每一项选择：你们依据哪些论据确定了你们认为优先的现象——针对每个介质，以及针对连接各介质的整体策略？你们的来源和推理是什么？

d. 你们的量纲分析是否自洽？你们的数量级是否与已知情况相符？

e. 你们建模选择的优势与局限是什么？

评价标准：
- 能否突出方法中最重要的参数和推理，尤其是在最终方框图中。
- 能否展示各现象之间是如何相互联系的。
- 能否解释并论证数值模拟中的各项选择。
- 若 Matlab 代码可运行：所上传代码能否在教师电脑上直接通过“Run”命令运行。代码必须基于 `map.xlsx` 文件运行，且只能是单个文件。这一要求同样适用于周五的交付物。

| `2,3,7,8 TCDD` | 该污染源排放的 2,3,7,8-TCDD 质量（kg/年）。 |
| `Dioxines et furanes (PCDD + PCDF)（以 2,3,7,8-TCDD 当量的 kg 表示）` | 除 2,3,7,8-TCDD 以外的二噁英和呋喃（2,3,7,8-TCDD 在其自己的列中）。两列相加不会重复计算（kg 2,3,7,8-TCDD 当量/年）。 |

| `Benzo[a]pyrène、HAP、二噁英和呋喃、颗粒物（PM10…）` | 对城市而言，这些污染物出现在每个正方形单元的三行“城区（zone urbaine）”中：道路交通、传统壁炉、燃油供暖。它们针对同一正方形单元内所有城市整体计算（单元的城市面积和城市人口），而不是逐个城市计算。 |
| `Fluor`（氟） | “氟及其化合物（Fluor et ses composés）”一列通常已包含其他含氟产物列。作为一阶近似，仅使用“氟及其化合物”一列来计算某场址排放的含氟产物总质量。 |

【译注】实际 `map.xlsx` 中该说明列的英文表头还补充了：`HAP` 列为**除苯并[a]芘以外**的多环芳烃，总 PAH = HAP + Benzo[a]pyrène；二噁英两列相加得总 I-TEQ。

### 2.3 方框图（L1_1）建议骨架 —— 只放能算的环节

```
[源] B4 港口：Q_PM10 = 1.09e5 kg/yr, Q_COVNM = 3.28e5 kg/yr (map.xlsx)
   │ 连续点源，按 kg/s 输入：Q = M / (3.156e7 s/yr)
   ▼
[大气输运] 平流-扩散（风 U,V，Δt = 3 h，Vent1An/1Mois）
   │ 网格 70 km × 70 km；混合层高度 H（假设，需注明来源）
   ├──► [干沉降] v_d（PM10 ~ 1e-3–1e-2 m/s，来源：Deposition transfer processes 资料）
   ├──► [湿沉降] 冲刷系数 Λ ∝ 降水强度（precipitation_mm/year）
   └──► [化学降解] k_deg（COVNM，OH 自由基）
   ▼
[各单元近地面浓度 C(x,y)]  →  [土壤/淡水/海水沉积通量 F = (v_d + Λ H) C]
   ▼                                   ▼
[吸入暴露] 人口(城市/农村) × 呼吸量     [摄入暴露] 农业用地、渔业单元（USEtox %ingestion）
   ▼                                   ▼
[USEtox 表征因子] CF (CDUh/kg) → 健康影响（病例数 / DALY）
```

核心方程（周三口试需每个人都能解释）：

$$
\frac{\partial C}{\partial t} + \mathbf{u}\cdot\nabla C = \nabla\cdot\left(K\nabla C\right) + \frac{Q}{A\,H} - \left(k_{dep} + k_{wet} + k_{deg}\right) C
$$

- $C$：大气浓度 [kg·m⁻³]；$\mathbf{u}=(U,V)$：风速 [m·s⁻¹]；$K$：湍流扩散系数 [m²·s⁻¹]；$Q$：源强 [kg·s⁻¹]；$A$：单元面积 [m²]；$H$：混合层高度 [m]
- $k_{dep}=v_d/H$ [s⁻¹]；$k_{wet}=\Lambda$ [s⁻¹]；$k_{deg}$：降解速率 [s⁻¹]
- 显式有限差分 CFL 约束：$\Delta t \le \dfrac{\Delta x}{|\mathbf{u}|_{max}}$，扩散稳定性 $\Delta t \le \dfrac{\Delta x^2}{4K}$（参考 `SIMULATION_fd_evolution_pdes_lnotes.pdf`）
